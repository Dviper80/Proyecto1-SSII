Es necesario para el funcionamiento del proyecto: XAMPP, Python (preferinblemente superior a 3.5) y HeidiSQL, criptography "pip install cryptography argon2-cffi"
 mysql-connector-python obtenible con "pip install mysql-connector-python"

Documentación de la libreria sqlite3 usada: https://docs.python.org/3/library/sqlite3.html

Toda la documentación relativa al proyecto se encuentra en el archivo "PAI1-ST33.pdf" incluido el manual de arranque.
